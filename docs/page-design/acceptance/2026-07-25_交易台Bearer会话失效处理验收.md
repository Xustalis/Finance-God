# 交易台 Bearer 会话失效处理验收

## A. 流程与合同

| 项目 | 状态 | 证据 |
|---|---|---|
| 设计简报存在且与实现一致 | 通过 | `docs/page-design/briefs/2026-07-25_交易台Bearer会话失效处理设计简报.md` |
| 受影响路由与页面规范已更新 | 不适用 | 未改变路由、页面结构或既有页面合同 |
| 真实数据、时间与失败状态符合合同 | 通过 | 只以服务端 HTTP 401 触发会话失效；无客户端猜测或伪造 |
| 主操作及权限边界正确 | 通过 | 401 清除普通用户 token/用户投影并回 `/login` |
| Agent 上下文、快捷指令与工作流符合合同 | 通过 | Agent 流式请求 401 使用同一会话失效入口，未改变工作流逻辑 |
| 设置隔离与提醒留存 | 通过 | 管理员会话键未受影响；提醒 SSE 仅在 401 时清理普通用户会话 |
| 单元测试、类型检查、构建和烟测 | 通过 | 35 个定向测试通过；`vue-tsc --noEmit` 通过；Vite 生产构建通过；运行中 `/api/desk/bootstrap` 携有效 token 返回 200，浏览器 `/desk` 加载模拟账户且无 `UNAUTHORIZED` |
