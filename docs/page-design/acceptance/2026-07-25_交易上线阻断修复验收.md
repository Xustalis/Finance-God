# 交易上线阻断修复验收

| 项目 | 状态 | 证据 |
|---|---|---|
| 正式交易默认使用实时市场引用价 | 通过 | 前端显式提交 `market_mode=live`；后端仅该模式使用实时 provider |
| 历史模式不再被默认模拟账户时钟隐式启用 | 通过 | 历史 provider 与模拟业务时间仅在显式 `historical` 模式读取 |
| 指数等只读行情不能启用订单提交 | 通过 | `DeskQuote.trade_eligible` 被保留并进入统一引用价门禁 |
| K 线能力不可用不显示空白成功态 | 通过 | 空 bars 转为稳定 `MarketDataError`，由现有 `barsError` 显示 |
| 行情、K 线、订单与成交未使用 mock | 通过 | 变更只增加显式错误和资格门禁 |
| HTTP 环境语音限制可见且文字输入保留 | 通过 | 非安全上下文禁用语音按钮并显示 HTTPS 原因；Agent 文本输入未变 |
| 视觉令牌、双栏和工作区结构保持一致 | 通过 | 未新增颜色、卡片、导航或浮层 |
| 单元测试、类型检查、构建和烟测 | 不适用 | 用户明确要求跳过测试并快速部署；仅执行部署流水线健康检查与生产只读验证 |
