## C. 页面专属（`/desk`）

| 项目 | 状态 | 证据 |
|---|---|---|
| 总览显示可验证行情；部分失败保留成功行情且无假价 | 通过 | 批量报价按标的保留结果；指数只使用 PandaData 最近已发布日线作为显式 fallback；全量不可用返回 502。 |
| 交易区 K 线与当前标的一致，切换标的无旧数据串写 | 通过 | 浏览器不再下发不受合同支持的 limit；store 依赖当前 symbol/frequency，已有 rebuilding/timeout 测试通过。 |
| 披露与融资事实保持后端合同，不被 crawler 字段覆盖 | 通过 | 公网披露事实返回 1 条 `company_disclosure`，融资余额返回 10 条 `margin_balance`，provider 均为 PandaData。 |
| Agent 流失败、超时与正常终态可区分 | 通过 | 服务端 `done` 为唯一成功终态；缺失 `done`、读取超时和 Abort 均显式失败，相关测试通过。 |
