# 仿真止盈止损自动卖出验收

> 本功能的前端入口已按产品决定删除。后端兼容能力不在本次移除范围内。

| 验收项 | 结果 | 证据 |
| --- | --- | --- |
| 只从可卖持仓设置策略 | 通过 | 持仓行入口带入标的与可卖数量；服务端再次校验结算持仓 |
| 至少设置止盈或止损 | 不适用 | 持仓页不再提供保护策略表单；卖出统一在交易工作区 |
| 阈值绑定真实最新价 | 通过 | 创建时由服务端读取 PandaData 可信价格并校验上下界 |
| 离开页面后继续监控 | 通过 | 服务端 `MarketPoller` 在快照持久化后调用策略评估器 |
| 触发后自动市价成交 | 通过 | 复用即时市价订单与账本写入链路，订单直接进入 `filled` |
| 重复行情不重复卖出 | 通过 | 策略状态修订与订单幂等键共同约束；定向测试覆盖重复评估 |
| 失败时不伪造成功 | 通过 | 行情观察器记录异常；交易事务失败时策略保持未触发 |
| 可取消未触发策略 | 通过 | 持仓页提供取消操作，服务端只允许取消 `active` 策略 |
| Agent 不自动提交 | 通过 | 未向 Agent UI 动作目录暴露创建或取消策略动作 |
| 键盘、语义表格与可见错误 | 通过 | 使用原生表单、按钮、表格及既有工作区错误区 |
| 1024px 以下同路由适配 | 通过 | 未新增固定最小宽度或移动端交易流程 |
| 浏览器烟测 | 不适用 | 本轮未启动完整后端与已认证浏览器会话 |
