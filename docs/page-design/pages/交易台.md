# 交易台 `/desk`

## 目标

一个已认证的桌面交易工作区，左侧完成行情、持仓、自选和仿真交易，右侧保留与当前对象同步的 Agent。顶部使用 `FINANCE GOD`，提醒、钱包、交易记录、画像和设置不进入 Agent 能力。

## 工作区合同

| 工作区 | 服务端事实 | 用户操作 | 空/失败状态 |
|---|---|---|---|
| 总览 | `/market/overview`、融资余额事实、披露事实 | 选标的、刷新 | 显示上游时间/频率/freshness；无数据不展示替代价格 |
| 持仓 | `/simulation/accounts/current`、`/simulation/portfolio` | 确认初始资金建立仿真账户 | 无账户显示建立操作；无实时行情时市值和浮盈为“行情不可用” |
| 自选 | `/workspace/watchlists`、`/workspace/candidates` | 新建/改名/删除分组，增删标的，忽略候选 | 修订冲突要求刷新；候选说明为研究对象，不能下单 |
| 交易 | `/simulation/drafts`、复核/确认/提交接口、`/simulation/orders` | 草稿、复核、软风险确认、摘要确认、提交 | 必须具有真实行情引用价；所有写操作显示真实错误 |
| 我的 | `/simulation/accounts/current`、`/simulation/orders`、`/simulation/fills`、本人画像与设置接口 | 刷新仿真事实、保存本人设置 | 每类失败独立呈现；没有账户、订单或成交时显示真实空状态 |

## 联动规则

1. 切换工作区和标的递增 `contextVersion`，右栏标题与恰好三条快捷指令更新。
2. 行情缓存统一收集总览、持仓和自选标的；仅这一处轮询，页面隐藏时暂停。
3. Agent 只创建/读取后端工作流，不生成本地答案，不控制“我的”、设置或最终订单提交。
4. 工作流终态可在 `details` 中查看，未执行时只显示服务端 `queued` 事实。
5. Agent 收起后保留可见 rail；宽度、展开状态和工作区标签顺序保存在浏览器中，可通过布局入口重置。

## 可访问性与视觉

使用语义 `nav`、`table`、`form`、`details`、`button` 和可聚焦 `separator`；细规则表、暖纸面、深墨、朱红和深绿，避免卡片矩阵。宽屏左右同色对称并允许调整分栏，窄屏保留当前路由并上下排列。
