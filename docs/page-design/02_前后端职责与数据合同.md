# 前后端职责与数据合同

## 1. C/S 职责

| 责任 | 客户端 | 服务端 |
|---|---|---|
| 行情展示 | 轮询、展示上游时间与 stale/error | PandaData 凭据、标准化、缓存、持久 observation、质量判断 |
| 画像 | 采集、展示最小投影 | 保存原始画像、生成脱敏投影、版本化与访问控制 |
| 研究候选 | 展示解释和下一步 | 使用画像投影、行情和规则生成可研究候选 |
| 工作流 | 发起、订阅状态、显示回执 | 创建、调度、执行、租约、审计、恢复、事件流 |
| Agent 控制左侧 | 执行语义回执、处理 stale context | 下发 `UiActionDescriptor` 白名单和审计回执 |
| 提醒 | Toast、记录、已读操作 | 规则评估、历史、Outbox、SSE、已读/处理状态 |
| 用户设置 | 表单和本人提交 | 账户设置持久化；严禁暴露给 Agent |

## 2. 统一约定

- `/api/v1/*` 的认证/设置/画像使用 `{ success, data, error, meta }` 包络。
- `/api/*` 的交易域新接口也必须迁移到相同包络；历史裸 JSON 接口在适配层中兼容，不向页面组件泄露差异。
- Bearer Token 只由客户端认证层附加；PandaData 凭据永不下发浏览器。
- 所有写命令带 `Idempotency-Key`；所有可变上下文带 `context_version`；写回执包含 `applied | rejected | stale_context`。
- 时间使用 ISO-8601 UTC，展示层转为用户时区；金额和数量以字符串传输，避免浮点损失。

## 3. 交易台启动合同（P6）

`GET /api/desk/bootstrap`

```json
{
  "data": {
    "context_version": "42",
    "profile": { "projection_version": "3", "risk_level": "moderate", "completeness": 0.86 },
    "workspace": { "section": "information", "selected_symbol": "000001.SZ" },
    "quick_commands": [{ "id": "market-analysis", "label": "分析当前标的行情", "workflow_key": "market_context" }],
    "ui_actions": [{ "id": "select_symbol", "kind": "select_instrument", "scope": "workspace" }]
  }
}
```

`profile` 只能是 `SuitabilityProfileProjection`，不得包含收入、原始问卷、账户凭据或私密证据。`ui_actions` 不得包含设置、订单提交、撤单、资金划转、登录或任意 DOM/CSS 选择器。

## 4. 行情与提醒合同

`GET /api/market/overview?symbols=000001.SZ,600519.SH` 返回每个标的的 `last`、`change_percent`、`provider_time`、`retrieved_at`、`frequency`、`freshness` 和质量诊断。失败时返回显式错误；最后成功行情可标为 `stale`，但不改写为新鲜。

`GET /api/market/information-facts?symbol=000001.SZ&start_quarter=2026q1&end_quarter=2026q2` 返回 PandaData `get_fina_reports` 的公司财报披露事实。两个季度参数均为必填，格式为 `YYYYq1` 至 `YYYYq4`（小写 `q`，与 PandaData SDK 一致）。响应包含 `fact_kind=company_disclosure`、标的、请求时间以及每条事实的原始字段、上游端点、数据时间、摄取时间、证据引用和 freshness。它不生成新闻摘要、研报观点或交易结论。

`GET /api/market/sentiment-facts?symbol=000001.SZ&start_date=20260701&end_date=20260723` 返回 PandaData `get_margin` 的融资余额原始观察值，仅支持中国股票。日期必须成对提供并使用 `YYYYMMDD`，省略时读取最近 30 个自然日。响应包含 `fact_kind=margin_balance` 与同样的来源证据字段；不返回恐惧/贪婪标签、情绪分数或交易信号。

两个事实接口都是只读、`trade_eligible=false` 的市场研究数据。上游为空、权限不足、格式漂移或网络失败时返回显式错误，不以示例文本、缓存摘要或模型推断替代。浏览器显示来源时间和错误状态，并把情绪解释交给后续具有合格证据输入的工作流。

`GET /api/alerts?cursor=...` 为历史分页；`GET /api/events?cursor=...` 为 SSE。告警事件的去重键由服务端决定，至少包含 `alert_id`、`severity`、`source`、`occurred_at`、`status` 和事实版本。

## 5. 工作流合同

当前已上线接口：

| 接口 | 用途 | 成功响应 |
|---|---|---|
| `POST /api/workflows` | 创建持久 `WorkflowRun` | 首次创建返回 `201`；相同用户、相同 `Idempotency-Key` 与相同语义请求重放时返回 `200`；响应体均为裸 `WorkflowRun` JSON |
| `GET /api/workflows/{run_id}` | 读取本人创建的运行状态 | `200` 与裸 `WorkflowRun` JSON；不存在或不属于当前用户时均为 `404` |
| `GET /api/workflows/{run_id}/progress` | 读取可轮询的真实进度快照 | `200`，返回状态、版本、已记录节点产物、已记录节点产物数量、注册节点总数、错误和终态标记 |

三个接口均要求 Bearer Token；`POST` 还必须携带 `Idempotency-Key`。创建请求至少包含 `workflow_key` 与 `request_intent`，并且必须提供以下其中一种版本化输入：

- `input_versions`：显式的 `{ object_type, object_id, version }` 数组；或
- `symbol` 与 `context_version`：交易台兼容写法，服务端将其规范化为一条 `instrument_context` 输入版本。

创建请求可选 `scope` 与 `task_plan_reference`。客户端不能提交工作流权限；权限由服务端命令边界决定。`WorkflowRun` 至少包含 `run_id`、`status`、`revision`、`workflow_key`、`workflow_version`、输入版本、已完成节点产物和错误。当前可能返回的状态以服务端领域模型为准，包括 `queued`、`running`、`completed`、`attention_required`、`failed`、`timed_out`、`blocked`、`cancel_requested`、`cancelling`、`cancelled` 与 `expired`。

`progress` 不是节点事件流，也不返回浏览器推算的百分比。`completed_node_artifact_count` 只统计已持久化的节点产物；`total_node_count` 来自对应版本的服务端工作流注册表。尚未记录节点结果时，客户端只能呈现“后端已接受，等待执行器”，不能用计时器模拟步骤完成。

当前**未上线**：

- `GET /api/workflows/{run_id}/events?cursor=...` 节点事件流；
- `POST /api/workflows/{run_id}/cancel` 取消请求；
- 领取、续租、恢复与执行节点的常驻 Worker。

因此，创建接口只会持久化一个 `queued` Run，不代表已开始执行。P4 在上述 Worker 与事件投影落地后，再补充取消和事件合同；客户端始终以服务端 Run 事实为唯一状态来源。

## 6. Agent 与动作合同

Agent 请求包含当前 `context_version` 和已授权的投影。服务端返回文本、`workflow_run_id` 和可选的语义动作：

```json
{ "action_id": "navigate_section", "parameters": { "section": "portfolio" }, "context_version": "42" }
```

客户端只在动作 ID 位于已下发白名单、参数通过本地 schema、版本仍匹配时应用；否则显示 `rejected` 或 `stale_context` 回执。订单提交与撤销始终由用户在独立确认流中执行。
