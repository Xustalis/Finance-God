# 持仓跳转交易卖出设计简报

## 用户与操作场景

用户查看模拟持仓后，需要从具体持仓直接进入交易工作区准备卖出，减少重复输入标的和数量。

## 页面任务与主要对象

持仓表的主要对象仍是模拟仓位。每行增加“卖出”动作，跳转到交易工作区并预填当前标的、卖出方向和可卖数量；不自动创建或提交订单。

## 信息层级与工作区区域

顶栏、横向工作区导航和右侧 Agent 不改动。持仓表在“已实现”后增加“操作”列；交易区沿用既有行情、K 线、账户校验和确认表单。

## 真实数据来源、频率、新鲜度与失败状态

持仓及可卖数量来自 `/simulation/portfolio`，属于明确标注的模拟业务数据；交易引用价继续由服务端实时市场合同提供。行情不可用、可卖数量不足或账户不可用时，交易区禁止提交并显示原因。

## 主要操作与启用条件

可卖数量大于零时启用“卖出”。点击后只更新当前标的与交易表单预填，并切换到“交易”；用户必须再次点击“立即卖出”，服务端仍会重读行情并校验可卖数量。

## 受影响路由与桌面宽度

仅 `/desk` 的持仓与交易工作区；1440px 主画布及低于 1024px 的同路由布局沿用现有横向表格滚动。

## 视觉与交互论点

沿用纸面、墨色、风险色和规则线。卖出使用风险色文字与细下划线，不新增卡片、弹窗、强调色或动效。
