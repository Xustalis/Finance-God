# Agent 模型动态快捷指令设计简报

## 用户与操作场景

用户在 `/desk` 切换工作区或标的后，需要看到与当前对象和脱敏画像有关、措辞自然且角度不同的任务入口，而不是四组反复出现的固定句子。

## 页面任务与主要对象

右侧 Agent 输入区展示由服务端模型即时生成的三条快捷指令。主要对象是当前工作区、当前标的和允许进入 Agent 的脱敏画像投影。

## 信息层级与工作区区域

顶栏、左侧标签和内容、浮层均不改。右侧 Agent 保持“消息线程 → 动态快捷指令 → 自由输入”；生成不可用时在同一区域显示明确状态，自由输入仍可使用。

## 真实数据来源、频率、新鲜度与失败状态

每次 desk bootstrap 随工作区或标的上下文调用现有模型运行时生成，不读取设置、凭据或原始画像。模型未配置、调用失败、非 JSON、数量错误或重复时返回显式错误，不使用固定文案兜底。

## 主要操作与启用条件

模型成功返回三条非空且互不重复的安全指令后可点击提交；提交条件继续由 Agent/Workflow 实时能力、`context_version` 和活动任务状态决定。生成失败不禁用自由输入。

## 受影响路由与桌面宽度

仅 `/desk`；1440 px 主画布及小于 1024 px 的同路由紧凑布局均沿用现有结构。

## 视觉与交互论点

视觉论点：沿用暖纸、深墨、细规则和无卡片指令列表，不增加强调色。内容计划：动态任务入口、显式生成状态、自由输入。交互论点：工作区/标的变化触发新一轮生成；成功时整体替换三条；失败时明确提示且不伪造推荐。
