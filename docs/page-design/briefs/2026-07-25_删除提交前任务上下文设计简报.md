# 删除提交前任务上下文设计简报

## 用户与操作场景

交易台用户在右侧 Agent 中阅读对话、观察正式任务并提交新问题。独立的“提交前任务上下文”重复左侧当前工作区与运行时状态，占用对话空间，本次按用户批注删除。

## 页面任务与主要对象

页面任务仍是与 Agent 对话和观察正式 Run；主要对象仍为当前对话与活动工作流。删除仅涉及前端摘要展示，不改变服务端上下文、决策、工作流或权限合同。

## 信息层级与工作区区域

顶栏、左侧标签和内容、提醒与“我的”浮层均不改。右侧 Agent 由标题栏直接进入活动任务运行区或对话线程，不再显示独立提交依据区。

## 真实数据来源、频率、新鲜度与失败状态

不新增或修改数据请求。PandaData 行情仍在左侧事实区展示上游时间、频率与 freshness；Bootstrap 和 Agent 错误仍在原有状态区域显式呈现。

## 主要操作与启用条件

主要操作仍为输入并提交 Agent 指令，启用条件仍由服务端 Bootstrap 上下文和 capability 决定。

## 受影响路由与桌面宽度

仅 `/desk`；1440px 主画布及低于 1024px 的同路由紧凑布局均删除该区块。

## 视觉与交互论点

- 视觉论点：沿用暖米色纸面、深墨文字和规则线，减少一个重复的定义列表区块。
- 内容计划：保留 Agent 标题、活动任务、消息线程、快捷指令和输入；删除提交依据摘要。
- 交互论点：不新增动效；原有消息流、工作流状态和输入反馈保持不变。
- 不引入新强调色、卡片或浮层，不改变朱红当前态与双线分栏。
