# “我的”面板与 Agent 布局偏好设计简报

## 用户与操作场景

已登录用户在 `/desk` 内查看仿真资金、订单与成交事实，或调整仅属于本人的显示设置；同时可按当前屏幕和任务密度收起、展开或调整 Agent 面板。用户可能在 1440px 宽屏进行并排研究，也可能在低于 1024px 的窗口中继续使用同一路由。

## 页面任务与主要对象

“我的”面板的主要对象是只读画像、仿真账户、仿真订单、仿真成交和用户设置。桌面布局的主要对象是左侧工作区、共享 Agent 面板及其可见 rail；布局偏好只影响浏览器呈现，不改变 Agent 能力、服务端权限或业务数据。

## 信息层级与工作区区域

- 顶栏左侧固定显示 `FINANCE GOD` 与“金融教父 · 投研与决策档案”，右侧只保留提醒和“我的”。
- “我的”按画像、钱包、交易记录、设置分区；钱包先展示现金总额、可用、冻结和保证金，交易记录分别展示订单与成交。
- 左侧工作区标签仍只包含总览、持仓、自选、交易；布局入口与标签导航分离，可调整标签顺序、Agent 展开状态与宽度。
- Agent 展开时保留当前工作区、标的、工作流和三条快捷指令；收起时内容隐藏但保留可聚焦、可恢复的 rail。

## 真实数据来源、频率、新鲜度与失败状态

钱包读取 `/api/simulation/accounts/current`；订单读取 `/api/simulation/orders`；成交读取 `/api/simulation/fills`。这些数据只在初始化相关交易工作区或打开“我的”中的钱包/交易记录时刷新，不加入 PandaData 行情轮询，并明确标注“仿真”。每类请求独立显示失败原因；成功时显示最近读取时间，失败不以示例资金、订单或成交替代。

## 主要操作与启用条件

用户可刷新仿真数据；没有仿真账户时可前往持仓工作区建立账户。设置保存只调用本人账户接口，不进入 Agent 上下文。Agent 展开/收起、宽度调整、标签排序和布局重置均可通过键盘完成；宽度拖拽只在 ≥1024px 的并排布局启用，窄屏保持上下排列。

## 受影响路由与桌面宽度

仅影响受保护路由 `/desk`。1440px 默认左右等宽；1024px 及以上允许将 Agent 调整为 32%–60% 宽度；低于 1024px 时继续挂载 `/desk`，左侧工作区在上、Agent 或其 rail 在下。

## 视觉与交互论点

| 论点 | 实现 |
|---|---|
| 编辑部气质 | 暖纸面、深墨字、双细线、密集数字表；字标为顶栏锚点 |
| 「我的」浮层 | 浅纸面、墨线框、偏移阴影；宽约至 760px；内部分页底边当前态 |
| 钱包/记录 | `wallet-ledger` 多列键值与 `history-table`；空态与错误独立 |
| 布局偏好 | 键 `finance-god:desk-layout:v2`；Agent 32%–60%；标签序可调可重置 |
| 交互 | 分隔线可拖 + 方向键；收起为 58px 竖排 rail；`prefers-reduced-motion` 下取消过渡 |

内容边界：品牌与全局入口负责定向；「我的」负责本人数据和设置；左侧负责市场与交易操作；Agent 负责当前对象的工作流上下文。
