# AI 添加自选与真实候选设计简报

## 用户与操作场景

用户在 `/desk` 的 Agent 对话中明确要求把某只股票加入自选，并在自选工作区查看基于真实市场事实生成的可研究候选。

## 页面任务与主要对象

AI 可通过版本化语义动作把一个规范 A 股标的加入当前自选分组；可研究候选只展示取得真实 PandaData 快照的标的。缺少真实行情的标的不进入候选表，全量行情不可用时显示明确失败。

## 信息层级与工作区区域

顶栏、左右分栏和 Agent 线程结构不改。Agent 返回正式动作回执后，左侧自选数据更新并切换到自选工作区；候选区继续使用现有语义表格承载真实来源、上游时间、五项解释和操作。

## 真实数据来源、频率、新鲜度与失败状态

候选行情只来自服务端 PandaData `QuoteBatch`。候选项必须包含 PandaData provider 与上游时间；部分标的失败时只排除失败标的，全部失败或无可验证行情时返回 `MARKET_DATA_UNAVAILABLE`，不生成占位候选或 mock。

## 主要操作与启用条件

“加入自选”仅在用户明确表达操作、服务端动作目录包含 `add_to_watchlist`、`context_version` 有效、标的代码通过校验且至少存在一个自选分组时执行。AI 不创建或删除分组，不移除标的，不提交订单。

## 受影响路由与桌面宽度

仅 `/desk`；1440px 与 `<1024px` 使用同一交互和数据合同，无布局变化。

## 视觉与交互论点

沿用暖米色纸面、深墨文字、朱红当前态和规则线；不新增颜色、卡片或动效。成功后的状态变化由现有自选表格和 Agent 动作回执表达。
