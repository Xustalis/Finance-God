# 正式交易台重建设计简报

> 结构与视觉段落已按当前 `frontend` 实现回写；数据合同仍以 `02_前后端职责与数据合同.md` 为准。

## 用户与操作场景

面向已完成画像的个人投资者，在桌面端查看真实 PandaData 行情、管理仿真账户，并通过右侧 Agent 发起研究和工作流。页面为操作工作区，不是营销页。

## 页面任务与主要对象

主对象为「当前交易上下文」：当前左侧工作区、所选标的、用户画像投影、行情新鲜度和未读提醒。左侧展示并编辑用户可操作的工作对象；右侧 Agent 读取经授权的上下文并返回工作流结果。

## 信息层级与工作区

- **顶栏**：`FINANCE GOD` 字标 + 副标「金融教父 · 投研与决策档案」；右侧仅「提醒」「我的」文字按钮（非图标-only）；「我的」从 Agent 能力目录中排除。
- **分栏**：左右同色纸面；默认 Agent 宽约 50%，可拖 32%–60%；双线分隔，非黑白对照。
- **左侧导航**：横向标签「总览 / 持仓 / 自选 / 交易」（非窄侧栏）；当前项朱红强调；「布局」菜单管理宽度、标签序与重置。钱包、交易记录、画像和设置集中在「我的」面板。
- **右侧 Agent**：`AI AGENT` 标题；输入框上方恰好三条纵向快捷指令（描边对话图标、无卡片底）；工作流以 `details` 展示服务端状态。
- **收起**：宽屏收为 58px 竖排 rail；窄屏改为上下布局，不另建移动流。

## 真实数据、频率与失败状态

- 行情：`GET /api/market/overview`，统一缓存轮询；显示 PandaData 上游时间、频率和 freshness。失败时显示错误/陈旧状态，不显示编造价格。
- 用户画像：`GET /api/v1/profiles/me/latest`，仅显示风险、期限、经验、完整度、版本等可读摘要；前端不在浏览器自行推荐买入。
- 提醒：`GET /api/workspace/notifications`。未读提醒以可关闭 Toast 展示，并在约八秒后只自动收起 Toast；记录由服务端留存。
- Agent：`POST /api/workflows` 创建后端工作流，`GET /api/workflows/:run_id` 查询状态。三条快捷指令由当前左侧状态的确定性映射生成，待服务端推荐合同到位后替换。

## 主要操作与启用条件

用户可切换左侧工作区、选择标的、刷新行情、发起研究和准备仿真交易方案。订单提交和撤单不属于 Agent 可执行范围；分析请求要求后端工作流可用，设置仅由用户本人提交。

## 路由与桌面宽度

主路由为 `/desk`；旧交易链接均重定向至该工作区。以 1440px 为主画布；低于 1024px 保持同一路由、改为上下布局和可见 Agent 折叠/下方放置，不建立单独移动交易流。

## 视觉与交互论点

| 论点 | 当前实现 |
|---|---|
| 编辑部金融终端 | 暖米色纸、深墨字、双细线、密集表格 |
| 左右同色 | 两侧均 `--paper`，职责靠线与字重区分 |
| 朱红 / 深绿 | 当前标签与未读用 `#c91418`；涨/通过用 `--positive`；跌/风险用 `--risk` |
| 无卡片矩阵 | 工作区用表格、规则分区、表单与浮层 |
| 上下文联动 | 标的/工作区改变更新右栏副文案与三条快捷指令 |
| 可观测状态 | 工作流显示服务端 status / run id；无节点事件时不伪造进度 |
