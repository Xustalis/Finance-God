# 交易图表主题统一设计简报

## 用户与操作场景

面向在桌面交易台查看指数或个股行情、切换 K 线周期并据此进行模拟交易判断的用户。用户需要在高密度工作区内快速辨认价格、涨跌、数据新鲜度与均线，不应被独立卡片或多彩装饰打断。

## 页面任务与主要对象

统一复用 `MarketChart`、Agent 消息时间线与业务空态的视觉语言。主要对象是当前标的行情、K 线、成交量、移动均线、周期选择、用户/Agent 消息，以及持仓、自选和复盘的无记录状态。

## 信息层级与工作区区域

顶栏、左侧工作区标签与浮层均不改动。左侧调整总览和交易工作区内的图表，并为持仓、自选、复盘补充报刊式空账页，解释数据进入条件、正式字段和操作边界，不伪造业务记录。右侧保留 Agent 时间顺序，将普通消息从大卡片收敛为规则线条目，正式任务与报告仍保留完整纸片容器。

## 真实数据来源、频率、新鲜度与失败状态

继续使用后端标准化的 PandaData 行情与 K 线合同，展示 `provider_time`、`frequency` 和 `freshness`。错误继续由现有可见错误区域呈现，不增加 mock、静默回退或伪造价格。

## 主要操作与启用条件

主要操作是切换 K 线周期。分钟周期仅在服务端能力允许时启用；指数等不支持分钟线的对象保持禁用并显示既有原因。图表主题调整不改变行情或交易权限。

## 受影响路由与桌面宽度

- `/desk` 的“总览”和“交易”工作区
- 主要验收宽度：1440px、1024px、680px
- 小于 1024px 时仍保留同一路由与原有上下布局

## 视觉与交互论点

沿用 `--paper`、`--ink`、`--muted-ink`、`--positive`、`--risk` 与规则线令牌，不引入新强调色。移除图表卡片圆角与封闭边框，使用上下规则线融入报刊式工作区；周期当前态使用墨色文字和下划线，不与全局朱红工作区当前态竞争。均线使用棕墨明度层级，涨跌使用项目既有正/风险色并保留正负符号作为非颜色信号。普通 Agent 消息去除偏移阴影和装饰折角，以双线、细线、字重和对齐区分角色；用户消息限制阅读宽度。业务空态使用三栏定义列表承载“进入方式、将显示内容、数据边界”，不使用假持仓、假行情或假复盘填充。
