# AI 交易策略填写交易单设计简报

## 用户与操作场景

用户在右侧 Agent 明确要求“制定交易策略并填写交易单”。策略需要经过正式工作流和版本化交易计划，完成后把可确定字段带入左侧模拟交易表单，由用户核对并手动提交。

## 页面任务与主要对象

主要对象是服务端生成的 `trade_plan` 及其中唯一启用的交易动作。Agent 不能直接成交，也不能在计划未确定数量时猜测数量。

## 信息层级与工作区区域

顶栏、工作区标签和 Agent 位置不变。工作流仍在右侧显示过程与报告；完成后左侧切到交易区，表单上方显示“AI 已根据交易计划填写”的状态说明。

## 真实数据来源、频率、新鲜度与失败状态

- 标的、方向、数量和订单类型来自版本化 `trade_plan`，不是浏览器或模型临时拼接。
- 交易区继续重新读取 PandaData 真实行情；行情不可用时禁止提交。
- 计划没有数量时数量保持空白；多个动作、限价动作或缺少计划产物时明确报错，不静默选取或降级。

## 主要操作与启用条件

仅当用户明确要求填写交易单、服务端选择 `trade_plan_generation`、工作流完成且返回唯一可表示的市价动作时自动填写。最终“立即买入/卖出”始终由用户操作，并继续经过服务端现金、持仓和行情校验。

## 受影响路由与桌面宽度

仅影响 `/desk` 的右侧 Agent 与左侧交易工作区。1440 px 和低于 1024 px 均沿用当前同路由布局。

## 视觉与交互论点

沿用暖纸、深墨、细规则和现有中性状态文字，不新增强调色、卡片或浮层。预填说明使用语义状态文本，清楚区分“已填写草稿”和“已下单”。
