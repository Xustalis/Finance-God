# 决策日志与交易复盘设计简报

## 用户与操作场景

模拟交易用户在建仓、加减仓与清仓后，需要回看当时可得信息、实际执行和画像反馈。

## 页面任务与主要对象

`/desk` 新增“复盘”工作区，主要对象是持仓周期 `TradeEpisode`，下辖不可变决策快照、成交事实、终局复盘和画像反馈。

## 信息层级与工作区区域

顶栏与右侧 Agent 不变。左栏第五个固定标签为“复盘”；上部是紧凑案例表，下部是选中案例的时间线和复盘结果。“我的 → 交易记录”仅提供入口。

## 真实数据来源、频率、新鲜度与失败状态

成交、账户和持仓是模拟事实；决策快照引用成交时 PandaData 行情版本。案例按需读取，不轮询。缺失主观信息显示“当时未记录”，读取或生成失败显示服务端错误。

## 主要操作与启用条件

选择案例、刷新、对失败复盘执行幂等重试。成交自动建立档案，不要求用户补录。

## 受影响路由与桌面宽度

仅 `/desk`；1440px 使用既有双栏，低于 1024px 保持同路由上下排列，低于 680px 时间线改为单列。

## 视觉与交互论点

沿用纸面、墨色、规则线与朱红当前态；案例列表使用语义表格，详情使用无卡片纵向时间线，不新增强调色或浮层。
