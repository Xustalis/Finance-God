# 仿真止盈止损自动卖出设计简报

> 本设计已撤回。卖出操作统一归属 `/desk` 的“交易”工作区，持仓页不再提供自动卖出、止盈止损或保护策略入口。后端历史策略接口保留兼容，但正式前端不再读取或操作。

- 用户与场景：用户在持仓页查看账户、数量、成本、市值和盈亏；需要卖出时切换到“交易”工作区。
- 页面任务与主对象：持仓页只展示模拟账户与模拟持仓，不承担订单或策略创建。
- 信息层级：删除持仓表“操作”列、“设止盈止损”入口和下方“自动卖出策略”区域。
- 数据与失败态：持仓仍读取服务端账本和真实 PandaData 行情；删除策略请求后，策略接口失败不再污染持仓错误状态。
- 主操作：持仓页仅刷新；买卖均在“交易”工作区提交。
- 路由与宽度：仅影响 `/desk` 持仓工作区，各桌面宽度沿用现有布局。
