# 交易台壳层与总览版式设计简报

> 已按 2026-07 实际前端实现回写，作为后续改版对照，而非未落地提案。

## 用户与操作场景

已登录用户在约 1440px 桌面交易台中阅读真实行情、管理仿真持仓与自选、完成一次需本人确认的仿真下单；右侧 Agent 始终跟随当前工作区和标的。版式参考财经报纸的纸面、字标与分栏密度，**不**用静态示例数据填充工作区。

## 页面任务与主要对象

单一路由 `/desk` 包含四个共享壳层工作区：总览（真实行情与事实）、持仓（仿真账户与持仓）、自选（分组及可研究候选）、交易（订单草稿至回执）。主要对象分别为行情快照、仿真账户/仓位、自选分组/候选、仿真草稿/订单。

## 信息层级与工作区区域

- **顶部**：左侧 `FINANCE GOD` +「金融教父 · 投研与决策档案」；右侧仅「提醒」「我的」文字按钮与竖线分割；未读朱红圆点。
- **左侧**：横向标签「总览 / 持仓 / 自选 / 交易」；当前项朱红字 + `#c91418` 底边；旁侧「布局」菜单管理 Agent 宽、标签顺序与重置。
- **总览内容序**：大盘指数表 → 市场情绪事实 → 市场资讯事实；表格列含上游时间、频率、freshness。
- **右侧**：`AI AGENT`、当前工作区/标的/context version、真实工作流回执、三条快捷指令（对话气泡 icon rail）、线框输入与发送。
- **我的**：画像、钱包、交易记录、设置独立浮层，不进入 Agent。

## 真实数据来源、频率、新鲜度与失败状态

行情只来自 `/api/market/overview`（及事实类 market 接口），通过单一 Pinia 缓存合并基准标的、持仓和自选标的，统一轮询；页面隐藏暂停，恢复立即刷新。页面显示 PandaData 上游时间、频率和 freshness；请求失败或没有行情时明确写「行情不可用」或错误文案，不造价。公司披露事实请求携带上一季度到当前季度的 `start_quarter/end_quarter`。账户、持仓、订单均由 `/api/simulation/*` 读取并标注仿真；自选和候选来自 `/api/workspace/*`；工作流只显示 `/api/workflows` 的服务端状态/错误。

## 主要操作与启用条件

用户确认初始资金后才创建仿真账户。订单必须有交易中的实时行情或休市后已发布的真实收盘价作为引用价格，依次经过草稿、风险复核、软风险确认（如有）、摘要确认、最终提交；所有写命令携带 `Idempotency-Key`。候选仅是研究对象，可忽略，不能直接买卖。自选编辑依赖服务端修订版本，冲突时提示刷新。

## 受影响路由与桌面宽度

影响 `/desk`、`/login?redirect=/desk`。`/desk?preview=1` 不再绕过认证。≥1024px 为可拖拽双栏（默认 Agent 50%，范围 32%–60%）；&lt;1024px 同一路由改为上下布局，Agent 可收为 rail（宽屏）或置于下方（窄屏）。

## 视觉与交互论点（与实现对齐）

| 论点 | 实现表现 |
|---|---|
| 暖象牙纸 + 深墨字 | `--paper` / `--ink` 全页同色，无黑白分栏 |
| 双线分栏 | 顶栏与主分栏 `3–4px double` |
| 朱红当前态 | 标签底边与未读点 `#c91418`；风险文案仍用 `--risk` |
| 深绿涨/通过 | `--positive`，仅涨跌与通过语义 |
| 报刊数字 | `--font-numeric` 用于字标、价格、`AI AGENT` |
| 无卡片矩阵 | 总览用表格与事实列表，不用仪表盘卡片 |
| 快捷指令 | 贴输入框、纵向、无卡片底、描边对话图标 |
| 布局可逆 | `localStorage` `finance-god:desk-layout:v2` + 重置入口 |
