# 仿真市价即时成交设计简报

## 用户与操作场景

已建立仿真账户的用户在 `/desk` 交易区，按 PandaData 最新有效行情完成一次买入或卖出，不处理专业订单生命周期。

## 页面任务与主要对象

页面只负责选择标的、方向和数量，并由用户点击一次执行。主要对象是仿真账户、真实行情、仿真订单与仿真成交。

## 信息层级与工作区区域

- 顶栏、四个主工作区标签和右侧 Agent 不变。
- 交易区依次显示真实行情、极简表单、最近一次成交回执和最近成交表。
- Agent 只可预填标的、方向与数量，不可提交。

## 真实数据来源、频率、新鲜度与失败状态

行情由服务端重新读取 PandaData，展示上游时间、频率和 freshness。行情不可用、现金不足、可卖持仓不足或服务失败时明确拒绝，不生成订单或成交。

## 主要操作与启用条件

“立即买入 / 立即卖出”是唯一主操作。仅在仿真账户可用、数量为正、行情有效且前端资金/持仓初检通过时启用；服务端再次完成权威校验并通过幂等键防重复提交。

## 受影响路由与桌面宽度

仅 `/desk` 的交易工作区；覆盖 1440px、1024px 临界宽度及 680px 窄宽，同一路由自适应。

## 视觉与交互论点

沿用暖纸面、深墨、双线与朱红当前态，不新增强调色或卡片。表单、回执和成交记录使用规则线、定义列表及语义表格；一次点击即确认仿真市价交易，不增加弹窗或第二确认步骤。
