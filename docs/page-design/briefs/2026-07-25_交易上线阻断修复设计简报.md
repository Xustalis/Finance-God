# 交易上线阻断修复设计简报

## 用户与操作场景

用户在正式 `/desk` 交易台读取 PandaData 实时行情、查看 K 线并提交模拟市价单；生产服务器当前使用 HTTP，文字 Agent 必须始终可用。

## 页面任务与主要对象

交易区只允许服务端标记为可交易的 A 股个股提交模拟订单。正式页面默认使用实时市场引用价，不读取历史模拟时钟。K 线能力不可用时显示明确错误，不展示空图冒充成功。

## 信息层级与工作区区域

顶栏、五个左侧标签、右侧 Agent 和双栏结构均不改。交易区沿用现有行情带、K 线和表单错误位；Agent 输入区在语音按钮下方显示安全连接限制，文字输入保持可用。

## 真实数据来源、频率、新鲜度与失败状态

- 行情和 K 线来自后端 PandaData 适配器。
- 服务端随行情下发 `trade_eligible`；指数日线仅供阅读，不能进入订单。
- bars 为空且带上游错误时返回稳定市场数据错误码，前端现有 `barsError` 显示失败。
- 不为价格、K 线、订单或成交增加 mock。

## 主要操作与启用条件

模拟市价单要求：模拟账户可用、数量有效、余额或可卖数量足够、行情有有效价格且 `trade_eligible=true`。语音要求安全上下文和浏览器麦克风能力；不满足时按钮禁用并说明原因。

## 受影响路由与桌面宽度

仅 `/desk`；沿用 ≥1440px 主画布、1024–1439px 紧凑双栏和低于 1024px 同路由上下排列。

## 视觉与交互论点

沿用暖米色、深墨、规则线和风险色，无新强调色、卡片或浮层。错误与限制放在原工作区邻近位置，避免改变操作路径。
