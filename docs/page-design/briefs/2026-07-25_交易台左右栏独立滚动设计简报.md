# 交易台左右栏独立滚动设计简报

## 用户与操作场景

桌面交易用户需要在左侧查看较长的行情、持仓、自选或交易内容，同时保留右侧 Agent 的当前对话、任务回执和输入位置。滚动其中一侧不应带动另一侧离开当前上下文。

## 页面任务与主要对象

调整 `/desk` 宽屏壳层的滚动所有权，不改变交易数据、Agent 合同或业务操作。主要对象是左侧工作区内容与右侧 Agent 线程/任务历史。

## 信息层级与工作区区域

顶部栏保持当前结构。宽屏下左右等宽分栏固定在顶部栏以下的视口内；左侧工作区导航与历史演示时间条固定，业务内容独立滚动；右侧 Agent 标题和输入区固定，线程或任务历史独立滚动。提醒、我的及其他浮层不变。

## 真实数据来源、频率、新鲜度与失败状态

不改变任何数据来源、轮询频率、新鲜度或错误状态；左侧滚动容器继续展示现有 PandaData 时间与失败信息，右侧继续展示服务端 Agent 与工作流事实。

## 主要操作与启用条件

用户可直接在对应栏内使用鼠标、触控板或键盘滚动。独立滚动仅在 `≥1024px` 双栏布局启用；低于该宽度时恢复上下排列和自然页面滚动。

## 受影响路由与桌面宽度

仅 `/desk`。主要验收宽度为 1440px，同时验证 1023px 与 680px 响应式边界。

## 视觉与交互论点

沿用暖纸、深墨、双线分栏和朱红当前态，不引入新颜色、卡片或动效。改动只明确滚动边界：双线仍承担左右职责分隔，滚动不会改变既有信息层级。
