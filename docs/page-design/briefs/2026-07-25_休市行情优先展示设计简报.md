# 休市行情优先展示设计简报

## 用户与操作场景

用户在交易台总览查看真实行情，或在历史演示账户中查看模拟时钟之前已经完成的 PandaData 分钟行情。即使当前休市或部分标的数据接入失败，已经成功取得的真实数据也应继续展示，失败标的必须单独说明。

## 页面任务与主要对象

页面任务是优先展示可验证的行情快照和 K 线。主要对象为 PandaData 行情、上游数据时间、实际频率、新鲜度、市场时段对齐状态，以及逐标的失败信息。

## 信息层级与工作区区域

- 顶栏、左侧工作区标签、右侧 Agent 与浮层不改。
- 总览行情头部先显示标的、价格与涨跌，再显示“交易中 / 休市·最近交易日 / 历史演示”等状态和上游时间、频率、新鲜度。
- 某个标的失败不清空其他成功标的；失败信息保留在行情区内。

## 真实数据来源、频率、新鲜度与失败状态

- 现实行情继续读取服务端 `/market/overview` 与 `/market/bars`，事实源为 PandaData。
- 历史演示继续读取 `/simulation/market/overview` 与 `/simulation/market/bars`，只展示模拟时钟之前已经完成的 PandaData 分钟线，避免未来信息泄漏。
- 客户端展示 `provider_time`、`frequency`、`freshness`、`session_alignment` / `market_status`。
- 批量读取按标的隔离失败；成功数据正常展示，失败标的及原因通过 warnings 显式呈现，不伪造行情。

## 主要操作与启用条件

刷新始终可用；加载期间禁用重复刷新。历史演示的进入下一交易时段操作及订单门禁不变。

## 受影响路由与桌面宽度

- 路由：`/desk` 的总览、持仓和交易工作区共用行情状态。
- 桌面宽度：1440px 主画布及小于 1024px 的同路由紧凑布局；不新增移动流程。

## 视觉与交互论点

沿用纸面、墨色、规则线和现有正负语义色，不引入新强调色。状态通过明确文字承载，不仅依赖颜色；不增加卡片矩阵、浮层或动效。
