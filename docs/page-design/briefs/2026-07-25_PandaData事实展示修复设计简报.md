# PandaData 事实展示修复设计简报

## 用户与操作场景

用户在 `/desk` 总览查看当前 A 股个股的融资余额与公司财报披露事实，需要快速区分业务指标、记录时间和标的元数据。

## 页面任务与主要对象

修复 PandaData 原始事实的页面呈现。主要对象是最新融资余额观察值和财报披露记录；不改变服务端事实合同，不生成摘要、观点或交易信号。

## 信息层级与工作区区域

顶部栏、工作区标签和右侧 Agent 不变。左侧总览中，融资余额条只呈现融资/融券业务指标；公司披露列表呈现每条记录的非空财务字段，记录时间继续由来源戳单独展示。

## 真实数据来源、频率、新鲜度与失败状态

数据继续来自 `/api/market/sentiment-facts` 与 `/api/market/information-facts`，上游分别为 PandaData `get_margin` 与 `get_fina_reports`。页面不改写事实值；请求错误、适用范围、mock 披露与跨标的隔离沿用现有状态。财报记录没有任何非空业务字段时明确显示“未返回可用财务指标”。

## 主要操作与启用条件

主要操作仍是刷新。仅当前标的是受支持的 A 股个股时加载事实；本次不新增操作或权限。

## 受影响路由与桌面宽度

仅 `/desk` 总览，覆盖 1440px、1024px 与现有窄屏自适应布局。

## 视觉与交互论点

沿用纸面、墨色、规则线和现有事实条，不引入强调色、卡片或新浮层。修复只减少无决策价值的结构字段与空字段噪声，并为金额使用等宽数字格式。
