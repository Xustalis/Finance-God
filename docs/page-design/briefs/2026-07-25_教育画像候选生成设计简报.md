# 教育画像候选生成设计简报

## 用户与操作场景

已完成画像的交易台用户在「自选」工作区查看可研究候选。画像中的教育限制继续用于报告和执行权限提示，但不再阻断研究候选生成。

## 页面任务与主要对象

页面任务是展示由服务端基于画像方向、仿真持仓和 PandaData 行情生成的可研究候选；主要对象为候选标的、五项解释、反方证据、未知项与行情来源。

## 信息层级与工作区区域

顶栏、四个左侧标签、右侧 Agent 与浮层均不改动。仅调整左侧「自选」工作区的候选可用性合同，移除教育模式专属不可用状态。

## 真实数据来源、频率、新鲜度与失败状态

候选继续由 `/workspace/candidates` 返回，行情来自 PandaData，并展示画像版本、方向、生成时间和候选行情时间。无画像、无方向、方向不受支持或行情不可用时继续显示明确失败状态，不提供虚构候选。

## 主要操作与启用条件

用户可忽略候选或为服务端判定可交易的候选申请研究型交易计划；候选不能直接下单。教育画像不再单独禁用候选生成，其余方向、行情和风险条件保持不变。

## 受影响路由与桌面宽度

仅 `/desk` 的「自选」工作区；≥1440px、1024–1439px 与 <1024px 均沿用现有布局，无宽度专项变化。

## 视觉与交互论点

沿用现有暖纸、深墨、规则线、朱红当前态和双线分栏；不引入新颜色、卡片或浮层。变更只删除已废弃的错误文案映射，候选表格和已有错误样式不变。
