# AI 原生流式回复设计简报

## 用户与操作场景

交易台用户提交概念说明、问候或功能解释等直接回答后，希望在模型生成期间立即开始阅读，而不是等待完整答案一次出现。

## 页面任务与主要对象

为 `/desk` Agent 的普通直接回答接入模型原生文本增量。工作流、研究报告、仿真订单草稿和回执仍按服务端正式状态或产物整体呈现。

## 信息层级与工作区区域

顶栏、左侧工作区、Agent 标题、快捷指令和输入区不变。流式片段写入当前 AI 纸片消息；生成中显示细朱红光标，结束后同一消息进入完成态。

## 真实数据来源、频率、新鲜度与失败状态

- 上游：配置的 OpenAI-compatible Responses API 原生 `response.output_text.delta`。
- 服务端：`POST /api/agent/desk/decision/stream` 使用 NDJSON 转发 `start / delta / done / error`。
- 直接回答结束后才固化完整正文并刷新后续快捷指令。
- 上游中断以 `error` 事件结束，前端将当前消息替换为明确错误，不补写本地答案。

## 主要操作与启用条件

启用条件沿用 `agent_answer`、有效 `context_version` 与无活动 Run。UI 动作在完整流成功返回后才执行；流未正常结束时不应用动作。

## 受影响路由与桌面宽度

路由仅 `/desk`；1440 px、1024–1439 px 与 `<1024 px` 使用相同行为。

## 视觉与交互论点

- **视觉论点**：墨字在当前纸片上逐段显现，不增加新的状态卡或强调色。
- **内容计划**：身份题签保持稳定，正文增量生长，结束后移除光标。
- **交互论点**：每个真实 delta 使用 280ms 轻淡入与 2px 模糊消退；光标仅表示连接仍在输出。
- 沿用纸面、墨色和朱红令牌；`prefers-reduced-motion: reduce` 下关闭淡入、模糊与光标闪烁。
