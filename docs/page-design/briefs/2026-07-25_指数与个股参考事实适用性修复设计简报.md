# 指数与个股参考事实适用性修复设计简报

## 用户与操作场景

用户在 `/desk` 总览切换上证指数、深证成指或沪深 300，并继续查看下方融资余额与公司披露事实。PandaData 的这两类事实只支持中国股票；指数不是合法查询对象。

## 页面任务与主要对象

保留指数行情与 K 线作为总览主要对象。融资余额、公司披露作为仅适用于 A 股个股的辅助对象：当前选择指数时显示适用范围，不发起无效请求，也不把“能力不适用”伪装成上游故障或 mock。

## 信息层级与工作区区域

- 顶栏、五个工作区标签、右侧 Agent 与浮层均不改动。
- 左侧总览继续先展示指数行情图。
- 下方两个参考事实区域在指数上下文显示同一条明确状态；切换到 A 股个股后恢复真实 PandaData 事实。

## 真实数据来源、频率、新鲜度与失败状态

- 指数行情与 K 线继续来自 PandaData，并保留上游时间、频率与 freshness。
- 公司披露来自 `get_fina_reports`，融资余额来自 `get_margin`，两者仅支持中国股票。
- 能力不适用显示状态，不进入 mock；仅个股真实请求发生获准的上游失败时才允许模块级显式 mock。

## 主要操作与启用条件

刷新继续刷新当前行情。事实读取仅在当前标的是非基准指数且不处于历史演示时启用；指数状态提示用户切换至 A 股个股查看。

## 受影响路由与桌面宽度

仅 `/desk`；1440px 主画布及 `<1024px` 同路由紧凑布局均沿用现有结构。

## 视觉与交互论点

沿用纸面、墨色、规则线和现有 `.empty-data` 状态样式，不引入新颜色、卡片或浮层。状态文案位于事实区域原位置，不影响朱红工作区当前态、双线分栏或 Agent 可见性。
