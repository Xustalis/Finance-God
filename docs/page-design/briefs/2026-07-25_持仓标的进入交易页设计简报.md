# 持仓标的进入交易页设计简报

## 用户与操作场景

用户在 `/desk` 持仓工作区查看模拟持仓，希望点击某个持仓标的后直接进入该标的的交易工作区。

## 页面任务与主要对象

把持仓表中的标的代码改为可聚焦入口；点击后同步当前标的并切换到交易工作区。该入口只导航，不预填方向、数量或提交订单；原“卖出”按钮继续承担卖出预填。

## 信息层级与工作区区域

顶栏、左右分栏和 Agent 不变。仅调整持仓表第一列，使用现有文字动作层级；交易工作区继续显示相应标的的真实行情、K 线和模拟交易表单。

## 真实数据来源、频率、新鲜度与失败状态

点击后复用统一 `setSymbol` 与交易区行情加载链路，行情仍来自 PandaData，并保留上游时间、频率和失败状态。不得保留旧标的行情冒充新标的。

## 主要操作与启用条件

任一有效持仓标的均可点击进入交易工作区。导航不受可卖数量限制；“卖出”按钮仍仅在可卖数量大于零时启用。

## 受影响路由与桌面宽度

仅 `/desk`；1440px 与 `<1024px` 同路由行为一致。

## 视觉与交互论点

沿用纸面、墨色和规则线，不新增颜色或卡片。标的入口使用墨色文字与下划线悬停/焦点反馈，不与朱红当前工作区状态竞争。
