# 统一证券代码与测试合同修复设计简报

## 用户与操作场景

交易台用户从本地恢复、总览选标的或 Agent 语义动作进入同一证券上下文。

## 页面任务与主要对象

修复 `/desk` 的 `InstrumentId` 一致性；主要对象是带明确交易所后缀的证券代码。

## 信息层级与工作区区域

不改变顶栏、左侧工作区、右侧 Agent 或浮层结构。仅统一上下文恢复、标的切换和 Agent UI action 的输入边界。

## 真实数据来源、频率、新鲜度与失败状态

行情仍来自 PandaData 服务端适配层；本次不改变轮询频率和 freshness 展示。非法或未知后缀不进入行情请求，不以猜测市场兜底。

## 主要操作与启用条件

合法 `InstrumentId` 必须包含受支持的交易所后缀并符合该市场代码格式；默认上下文固定为 `000001.SZ`。Agent 动作仍需动作目录、参数和 `context_version` 三重校验。

## 受影响路由与桌面宽度

仅 `/desk`；所有桌面宽度行为不变。

## 视觉与交互论点

沿用现有纸面/墨色令牌，不新增颜色、卡片、浮层或布局变化。总览指数标签仍作为当前正式控件合同。
