# 生产成交列表 502 修复设计简报

## 用户与操作场景

已登录用户在服务器部署的 `/desk` 交易工作区查看模拟成交记录。

## 页面任务与主要对象

恢复“最近成交”读取；主要对象为当前用户拥有订单对应的模拟成交事实。

## 信息层级与工作区区域

不改顶栏、工作区、Agent 或浮层，仅修复交易区既有成交列表的数据查询边界。

## 真实数据来源、频率、新鲜度与失败状态

成交来自 PostgreSQL `simulation_execution_fills`，按用户拥有的订单 ID 在数据库内过滤。请求失败仍显示既有明确错误，不使用 mock。

## 主要操作与启用条件

进入交易区或刷新模拟事实时读取最近成交；必须通过 Bearer 身份并只返回本人订单成交。

## 受影响路由与桌面宽度

`GET /api/simulation/fills` 与 `/desk` 全部桌面宽度；无版式变化。

## 视觉与交互论点

沿用既有纸面、墨色、规则线和错误态，不引入新颜色或交互。
