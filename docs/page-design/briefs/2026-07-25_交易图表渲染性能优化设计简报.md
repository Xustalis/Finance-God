# 交易图表渲染性能优化设计简报

## 用户与操作场景

已认证的零售或专业交易用户在 `/desk` 查看并切换分时、日线、周线、月线 K 线。行情轮询或周期切换时，图表需要及时更新且不得改变价格、成交量与均线的业务含义。

## 页面任务与主要对象

页面任务不变：展示当前标的的真实 PandaData 行情与 K 线。主要对象是按时间升序的 `DeskBar` 序列及由其生成的蜡烛、成交量和 MA5/10/20/60。

## 信息层级与工作区区域

顶栏、左侧工作区标签、右侧 Agent 和浮层均不改动。仅优化左侧行情图表的数据预处理，不改变可见信息、周期按钮、图表系列或布局。

## 真实数据来源、频率、新鲜度与失败状态

数据仍来自后端 PandaData 适配合同；轮询频率、上游时间和 freshness 展示不变。前端服务边界将 Decimal JSON 字符串规范为有限数字，并按时间排序、对相同时间保留最后一条服务端记录；历史模拟分钟数据切换为日线时按交易日聚合。非法数值或时间进入显式错误通道，不生成或替换任何行情值。

## 主要操作与启用条件

用户仍可在有真实 K 线数据时切换分时、5 分、15 分、1 小时、日线、周线和月线。服务端频率请求规则不变：分钟周期请求 `1m`，其余周期请求 `daily`。

## 受影响路由与桌面宽度

仅 `/desk`；所有既有桌面宽度和小于 1024px 的同路由紧凑布局均保持不变。

## 视觉与交互论点

沿用全部纸面、墨色、正负语义色与朱红当前态令牌，不引入新颜色、卡片、规则线或浮层。优化只合并重复排序、聚合与均线遍历，因此不与双线分栏、横向标签或现有键盘交互冲突。
