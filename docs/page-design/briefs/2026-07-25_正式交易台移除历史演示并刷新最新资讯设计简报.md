# 正式交易台移除历史演示并刷新最新资讯设计简报

## 用户与操作场景

用户在正式交易台查看当前市场与公开财经资讯，不进入历史时点模拟，也不接受演示资讯替代真实数据。

## 页面任务与主要对象

总览继续以真实行情与公开资讯为主要对象；持仓仅展示模拟账本和真实行情估值。移除正式 UI 的历史演示入口，避免现实资讯被历史模式屏蔽。

## 信息层级与工作区区域

顶栏、五个工作区标签、右侧 Agent 与浮层均不改动。持仓账户标题右侧只显示“实时行情估值”与账本修订；总览市场资讯保留来源、发布时间、抓取时间、新鲜度与失败状态。

## 真实数据来源、频率、新鲜度与失败状态

市场资讯来自服务端 `/api/market/news` 公开资讯 crawler。首次加载可读取五分钟内的真实缓存；用户点击总览“刷新”时请求 `refresh=1` 强制重新抓取。失败显示错误；若服务端只能返回上次成功的真实缓存，则显示 stale、抓取时间与警告，不使用 mock 或历史演示内容。

## 主要操作与启用条件

总览“刷新”始终可在非加载状态触发，并并行刷新行情、PandaData 事实与公开资讯。正式页面不再提供“进入历史演示”操作。

## 受影响路由与桌面宽度

仅 `/desk`；1440px 主画布与低于 1024px 的同路由紧凑布局均沿用现有壳层。

## 视觉与交互论点

沿用暖纸、深墨、朱红当前态与双线分栏，不引入新色彩或卡片。资讯新鲜度继续由文字、时间和错误状态表达；本次不新增动效。
