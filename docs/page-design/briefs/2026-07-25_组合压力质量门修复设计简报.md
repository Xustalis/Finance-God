# 组合压力质量门修复设计简报

## 用户与操作场景

交易台用户从 Agent 发起组合压力研究后，需要依据真实工作流节点判断任务是否完成；成功的确定性组合计算不能被误报为质量门失败。

## 页面任务与主要对象

主要对象是服务端持久化的 `portfolio_stress` WorkflowRun。页面继续展示运行状态、节点产物、错误与重试操作，不在浏览器推断工作流结果。

## 信息层级与工作区区域

`/desk` 壳层、左右分栏和 Agent 历史详情结构不变。错误区域将已知内部质量门错误码转换为说明原因和下一步的人类文案，其余服务端错误保持原样，避免掩盖未知故障。

## 真实数据来源、频率、新鲜度与失败状态

组合成本与持仓来自仿真组合投影，持仓行情来自 PandaData 服务端适配器。确定性计算成功且全部持仓行情快照齐全时明确通过质量门；缺失行情或服务异常继续走显式节点失败，不伪造数据。

## 主要操作与启用条件

任务成功后继续执行后续 Agent 节点并生成正式产物。真实质量门失败时仍进入“需要关注”，允许按原输入重试或在服务端确认可复用时从失败节点继续。

## 受影响路由与桌面宽度

仅 `/desk` 的 Agent 运行区与任务历史错误文案受影响；1440px、低于 1024px 的既有布局均不改变。

## 视觉、内容与交互论点

- 视觉论点：沿用暖纸、深墨与风险色文字，不增加容器或强调色。
- 内容计划：状态、节点、可读错误、重试操作维持现有顺序。
- 交互论点：不新增动效；保留现有历史切换和重试反馈。
