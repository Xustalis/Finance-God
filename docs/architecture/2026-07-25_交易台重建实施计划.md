# 交易台重建：现状、修正与分期

## Context Map

| 范围 | 现有实现 | 本次正式前端的改动 |
|---|---|---|
| `frontend/src/router.ts` | 所有交易路由都转向 `/rebuilding` | 恢复统一的 `/desk` 工作区路由 |
| `frontend/src/views/RebuildingView.vue` | 占位页 | 保留为历史文件，不再作为交易路由目标 |
| `frontend/src/services/tradingDesk.ts` | 无 | 统一真实 API、认证和可见错误 |
| `frontend/src/stores/tradingDesk.ts` | 无 | 单一轮询与跨栏上下文状态 |
| `frontend/src/views/TradingDeskView.vue` | 无 | 左右对称工作台、设置和提醒界面 |
| `backend/server.py` 与 `market_data/*` | 请求驱动、进程内行情缓存 | 后续改为服务端采集与持久化事实 |
| `workflow_*` | 有持久模型、无公共执行/事件 API | 后续增加 Worker、查询和 SSE |

风险：新前端不会改变账户或订单状态；后端成功响应格式有 `/api/v1` 包络和 `/api` 原始 JSON 两种，服务层将它们隔离。数据库迁移、SSE 和工作流 Worker 不在本次前端提交中。

## 必须修正的产品表述与边界

1. “推荐购入股票”应改为“可研究候选”。个股操作需展示行情时间、适配理由、风险/反方证据和未知项，并经过计划、复核和用户确认。
2. “所有按钮均可被 Agent 获取”不能等同 DOM 扫描或任意点击。应由服务端下发版本化 `UiActionDescriptor` 白名单；设置、提交、撤单、认证与资金事实永远不在其中。
3. “较长间隔”必须有范围与 SLA。建议开市时：持仓/自选 60 秒、研究候选 5 分钟、其他已收录标的 15 分钟；响应始终显示实际上游时间和实际频率。
4. Toast 自动消失、用户关闭、标记已读、处理完成是四种不同状态，不能互相替代。
5. Agent 的画像输入必须是脱敏、版本化的 `SuitabilityProfileProjection`；现有完整 objective profile 不能继续作为隐式最佳努力上下文。

## 分期交付与可观测验收

| Phase | 交付 | 可运行与可观测验收 |
|---|---|---|
| P0 合同与边界 | 标的范围、采集 SLA、提醒分级、Agent 权限矩阵、Desk 合同 | 合同样例/错误码/权限矩阵评审通过 |
| P1 数据底座 | `market_observations`、`market_latest`、采集/告警运行记录、规则版本 | `alembic upgrade head` 后可写 observation、重建 latest、查询一次 fetch run |
| P2 行情 Worker | 独立调度、租约、PandaData 写入、重启恢复 | Worker 重启无重复或漏采；运行记录含间隔、耗时、上游时间和失败原因 |
| P3 告警与事件流 | 确定性异动规则、Outbox、通知历史、SSE cursor | 写入测试 observation 后只生成一个 alert；浏览器可从 cursor 补收 |
| P4 工作流生产化 | `POST/GET/cancel /workflows`、领取/续租/恢复 Worker、节点事件 | 可观察 `queued → running → completed/failed`；进程重启后恢复或显式失败 |
| P5 Agent 主控桥接 | 意图路由到唯一 `WorkflowRun`、画像投影、三条快捷指令 API | 每次请求可追溯到画像/数据/工作流版本；设置不进入上下文 |
| P6 左右联动合同 | Desk bootstrap、`UiActionDescriptor`、动作回执与审计 | 每条动作返回 `applied/rejected/stale_context`，禁止动作有可测拒绝 |
| P7 正式前端 | `/desk`、真实行情、画像摘要、Agent、提醒、设置 | Vitest + 浏览器：初始化、联动、失败状态、设置隔离、无授权动作 |
| P8 端到端与运维 | 指标、结构化日志、失败演练、权限测试 | 采集→告警→SSE→页面→Agent 解释 E2E；PandaData 故障显示 stale/error |

## 本次边界

本次交付 P7 的正式 UI 与真实 API 接线，并留下 P0–P6 的可实现合同计划。由于后端尚未提供持久工作流查询/事件流、画像筛选候选、提醒历史和 Agent 动作回执，UI 明确显示对应未接入状态，不假造服务端结果。
